# 🎓 EduBridge

EduBridge is an Online Learning Platform for students to explore courses, learn new skills and grow.

## ✨ Features
- Browse Courses
- Student Login & Register
- Course Details Page
- Clean & Modern Design
- Responsive for Mobile & Desktop

## 🛠️ Technologies Used
- PHP
- MySQL
- HTML
- CSS
- JavaScript

## 🚀 How to Run
1. Download XAMPP and start Apache & MySQL
2. Copy this project to `htdocs` folder
3. Import database from `database` folder
4. Open in browser: `http://localhost/EduBridge`
